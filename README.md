# Financial & Regulatory Reporting

A quarterly financial and regulatory reporting pack for a fictional bank: balance sheet and P&L from general-ledger balances,
key ratios, an asset-quality return (GNPA, NNPA, provision coverage), an illustrative capital adequacy ratio, reconciliations,
control checks and the reporting documentation (report specification, data lineage, controls checklist). Built with **SQL**,
**DAX** and a **Power BI** report layout.

> **Synthetic data, illustrative rules.** The bank, its branches, GL balances and loan book were generated by
> `01. Dataset/generate_dataset.py` (seed 51). No real bank data is used. Classification cut-offs, provision rates and risk
> weights are **simplified for learning** and are not regulatory calculations or advice. The project builds on my MBA in Banking
> Technology and my banking internship, rebuilt on made-up data so it can be shared.

## Business questions
1. How did the bank perform in FY 2024-25 vs FY 2023-24 (balance sheet, P&L, margins)?
2. What is the asset quality (GNPA, NNPA, PCR, SMA), and does the source system classify loans correctly?
3. Are provisions enough, and is capital adequate (illustrative)?
4. Do the GL and the loan sub-ledger reconcile, and do the control checks pass?

## Key findings
| # | Finding | Evidence |
|---|---|---|
| 1 | Total assets reached **₹2,521 Cr** at Mar-25. Advances grew **16.0%** and deposits **14.0%**, but net profit fell **26.3%** to ₹8 Cr. | `01`, `02` |
| 2 | Margins are being squeezed: CASA fell from **40.1% to 31.3%**, so interest expended rose **31.2%** and NIM fell from **4.35% to 3.34%**. | `02`, `03`, `11` |
| 3 | Gross NPA rose from **3.85% to 7.08%** (net NPA 4.38%, PCR 39.8%). Agriculture has the highest GNPA ratio (**8.55%**); MSME holds **62.1%** of all NPAs. | `04`, `06`, `07` |
| 4 | **33 loan-quarters** were 90+ DPD but still tagged Standard in the source system, understating reported GNPA in most quarters. | `05` |
| 5 | Illustrative CRAR declined from **20.77% to 16.49%** as RWA grew faster than reserves; still above a 9% reference level. | `10` |
| 6 | Advances reconciliation shows **3 breaks** (Dec-23 +412.6 L, Sep-24 -287.3 L, Mar-25 +655.9 L). 4 borrower groups exceed the 5% of Tier 1 internal watch level. | `09`, `12` |

## Data cleaning
| Table | Issue / action | Count |
|---|---|---:|
| ChartOfAccounts, Deposits, Branches | No issues found (copied as is) | 0 |
| GLBalances | Amounts exported as text with thousand separators converted to numbers | 3 |
| GLBalances | GL codes not in the chart of accounts (checked) | 0 |
| LoanBook | Duplicate extract rows removed | 40 |
| LoanBook | Segment names standardised ('HOME LOAN' -> 'Home Loan') | 43 |
| LoanBook | Added DPDBucket (days past due band) | 58,044 |

Asset-class tags are deliberately **not** corrected in cleaning; misclassification is reported as an exception (script `05`).

## SQL scripts
| Script | Question |
|---|---|
| `01_Balance_Sheet.sql` | What does the balance sheet look like at 31 Mar 2024 and 31 Mar 2025 (by report line)? |
| `02_Profit_And_Loss.sql` | What is the profit and loss for FY 2023-24 and FY 2024-25 (by report line)? |
| `03_Key_Financial_Ratios.sql` | How did NIM, cost-to-income, ROA and CASA move each quarter? |
| `04_Asset_Quality_Summary.sql` | What are gross NPA, net NPA and the provision coverage ratio each quarter, as reported and as corrected? |
| `05_Asset_Classification_Exceptions.sql` | Which loans are more than 90 days past due but still tagged Standard (exception report)? |
| `06_NPA_By_Segment.sql` | Which loan segments carry the most NPAs at 31 Mar 2025 (corrected classification)? |
| `07_NPA_Movement.sql` | How did gross NPAs move each quarter (opening, additions, reductions, closing)? |
| `08_Provision_Adequacy.sql` | Is the provision held enough for each asset class at 31 Mar 2025 (illustrative rates)? |
| `09_GL_Subledger_Reconciliation.sql` | Does the GL advances balance (GL 1210) agree with the loan sub-ledger each quarter? |
| `10_Capital_Adequacy_Illustrative.sql` | What is an illustrative capital adequacy ratio (credit risk only) each quarter? |
| `11_CASA_By_Branch.sql` | What is the CASA ratio by branch at 31 Mar 2025, and how did it change from 31 Mar 2024? |
| `12_Top20_Borrower_Concentration.sql` | How concentrated is lending: top 20 borrowers as a share of advances and of Tier 1 capital (31 Mar 2025)? |
| `13_PL_Variance_Review.sql` | Which P&L lines moved more than 15% quarter on quarter (analytical review for the reporting pack)? |
| `14_Balance_Sheet_Control_Check.sql` | Do total assets equal total liabilities plus equity in every quarter (control check)? |

## How to run
```bash
pip install pandas numpy
cd "01. Dataset"
python generate_dataset.py
python clean_dataset.py
cd ..
sqlite3 bank.db < "02. SQL Scripts/00_Create_Tables_And_Load.sql"
sqlite3 -header -csv bank.db < "02. SQL Scripts/04_Asset_Quality_Summary.sql"
```
